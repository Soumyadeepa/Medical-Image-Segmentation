
# Medical Image Segmentation

This repository brings together implementations of deep learning models for medical image segmentation using PyTorch.

The project explores different neural network architectures and approaches for segmenting medical images, with an emphasis on understanding model designs, experimenting with their capabilities, and evaluating segmentation performance.

The repository includes a range of models, from convolutional encoder–decoder networks to attention-based, transformer-based, and multi-encoder approaches. Each implementation is organized separately to make the code easier to navigate, study, and compare.

The notebooks provide a foundation for experimentation, visualization, and further development in medical image analysis.

## Technologies

- Python
- PyTorch
- Jupyter Notebook / Kaggle

This repository is intended for learning, experimentation, and research-oriented exploration of deep learning techniques for medical image segmentation.
